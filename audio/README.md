# Урилга background music — source & license

All 18 tracks in this directory are instrumental works by **Kevin MacLeod**
(incompetech.com), licensed under **Creative Commons Attribution 4.0**
(https://creativecommons.org/licenses/by/4.0/). This license explicitly
permits commercial use, redistribution, and self-hosting — the only
requirement is attribution, which is shown in the sender's music picker and
in the recipient-side player's toggle-button tooltip (see `js/invite-music.js`).

No commercial/copyrighted songs (e.g. by mainstream artists) are used
anywhere in this feature — every file here is instrumental, royalty-free,
and traceable to a single, well-documented source.

Files were downloaded from the Internet Archive's mirror of Kevin MacLeod's
official "Royalty Free (2017)" album
(https://archive.org/details/Kevin-MacLeod_Royalty-Free_2017_FullAlbum),
which is a faithful copy of the same catalog published at incompetech.com.
